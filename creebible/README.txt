LITTLE BEAR'S FULL BIBLE — GITHUB PAGES EDITION

This folder is already built. No npm install or coding is required.

PUBLISH ON GITHUB PAGES

1. Create a new empty GitHub repository.
2. Upload EVERY file and folder from this folder into the repository root.
   The index.html file must be at the top level of the repository.
3. Open the repository's Settings > Pages.
4. Under Build and deployment, choose "Deploy from a branch".
5. Select the main branch and /(root), then Save.
6. GitHub will show the public Pages address when publishing is complete.

OFFLINE USE

Open the published site once while connected to the internet. The app shell is
then available offline. To save the complete Bible, open About and tap
"DOWNLOAD ALL 66 BOOKS" while online. All 66 books will then remain on that
device for offline reading as long as its browser data is not cleared.

IPHONE INSTALLATION

Open the GitHub Pages address in Safari, tap Share, then "Add to Home Screen".
